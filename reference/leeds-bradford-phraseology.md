# How Leeds talks: reference exchanges

Not a drill (you won't be landing at Leeds Bradford), but useful for recognising what you'll
hear on Leeds Radar 134.580 and Leeds Tower 120.305 while transiting. Values are illustrative.

## Arrival from the west via Salts Mill to runway 14 (GA)

| Station | Transmission |
|---|---|
| Pilot | Leeds Radar, G-CZIA, information Delta, QNH 1017, inbound for landing |
| ATC | G-CZIA, Leeds Radar, pass your message |
| Pilot | G-CZIA, QuikR microlight, Kirkbride to Leeds Bradford, 8 miles north-west of Keighley, altitude 3000 feet, QNH 1017, VFR, request join via Salts Mill, flight details emailed |
| ATC | G-IA, squawk 5627 |
| Pilot | Squawk 5627, G-IA |
| ATC | G-IA, identified. Cleared to enter the Leeds control zone via Salts Mill, VFR, not above altitude 3000 feet, Leeds QNH 1017, report Salts Mill |
| Pilot | Cleared to enter the Leeds control zone via Salts Mill, VFR, not above altitude 3000 feet, QNH 1017, wilco, G-IA |
| Pilot | G-IA, Salts Mill |
| ATC | G-IA, contact Leeds Tower 120.305 |
| Pilot | Leeds Tower 120.305, G-IA |
| Pilot | Leeds Tower, G-CZIA, Salts Mill, altitude 3000 feet |
| ATC | G-IA, Leeds Tower, join right base runway 14, descend to height 1500 feet, QFE 995 hectopascals, report right base |
| Pilot | Join right base runway 14, descend to height 1500 feet, QFE 995 hectopascals, wilco, G-IA |
| ATC | G-IA, number 2, following an Embraer 175 on 5 mile final, caution wake turbulence, report final |
| Pilot | Number 2, traffic in sight, wilco, G-IA |
| Pilot | G-IA, final 14 |
| ATC | G-IA, runway 14, cleared to land, surface wind 170 degrees 9 knots |
| Pilot | Runway 14, cleared to land, G-IA |

Points worth noticing:
- Leeds elevation is 681 ft, so QFE ≈ QNH − 22 and is usually below 1000: say **hectopascals**.
- Airliner traffic on Leeds Radar: “descend to altitude 4000 feet, vectors ILS runway 32”, “contact Leeds Tower 120.305”. None of it is for you, but it fills the gaps you need to call in.
- Listening squawk 2677 when monitoring 134.580 near the zone without a service.

## Leeds VRPs (UK VRP dataset, AIRAC 3 September 2026)
Arthington Viaduct (ATH), Chain Bar Roundabout (CBR), Dewsbury (DBY), Eccup Reservoir (ECP), Harrogate railway
station (HGT), Salts Mill (SML). Keighley is no longer one: use it as a landmark for position reports, not as a VRP.
Salts Mill, Eccup Reservoir and Arthington Viaduct are inside the CTR; Chain Bar and Dewsbury are under CTA 3.
The dataset notes that VRPs are reporting references: pass near them rather than overhead.
