Claude

Optional. With an Anthropic API key, Claude takes over as controller if you leave the script (diversion, weather, change of plan) and writes your debrief. The key stays in this browser.

Controller voice

Each unit gets its own voice, so Leeds and Edinburgh sound like different controllers, and other stations take the next voices along. Choose one here to use it for every controller instead. Voices differ by device: on a Mac, Chrome's “Google UK English” voices sound the most natural, and Apple offers Oliver, Kate and Serena as downloads under System Settings → Accessibility → Spoken Content → System voice.
